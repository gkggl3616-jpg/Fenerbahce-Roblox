# Arayüz önizlemeleri

Bu klasördeki görüntüler **Roblox ekran görüntüsü değildir**. Oyunun kendi arayüz kodu Roblox dışında
çalıştırılıp kurduğu ekran ağacı tarayıcıda çizilmiştir: yerleşim, yazılar, renkler ve ölçüler oyunun kodundan gelir;
3B sahne, ışık ve Roblox'un yazı tipi burada yoktur. Roblox'taki görünüm küçük farklar gösterebilir.
